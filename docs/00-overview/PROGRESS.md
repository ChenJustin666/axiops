## 当前执行顺序

1. 对现存身份数据完成兼容盘点和映射导入，再完成权限管理前端验收；AxiOps 是唯一产品品牌。
2. 完成 CI/CD 项目环境、服务 revision、K8s YAML 闭环，再接入 Helm、主机 Agent、回滚和通知。
3. 完成 Kubernetes 资源归属与统一授权。
4. 开始监控、日志目标服务。
5. 继续资产、Agent、AI 和统一前端体验。

## 进度更新规则

功能只有在代码、迁移、文档和测试记录同时完成后才能标记“已完成”。环境原因未执行的测试必须标记“阻塞”，不能按通过记录。后端完成但前端工作流未闭环的模块保持“进行中”。
