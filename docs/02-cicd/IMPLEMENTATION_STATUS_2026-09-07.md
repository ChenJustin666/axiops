## 本轮验收步骤

1. 重启 CI/CD API，使工作流运行接口的新校验逻辑生效；Platform API 和 Workflow Worker 不需要重启。前端 Vite 服务支持热更新，刷新页面即可。
2. 登录 AxiOps，进入 `CI/CD -> 项目 -> 工作流`，点击“快速发布”。
3. 第一步选择有运行权限的工作流、服务和 Revision；无运行权限的工作流不会出现在快速发布入口可选列表中。
4. 第二步选择状态为“已验证”的测试环境，确认页面显示集群和 Namespace；未验证环境不能选择。
5. 第三步检查新增/更新/删除/未变化资源摘要和资源明细。生产或开启发布审批的环境必须显示审批提示。
6. 点击“确认并执行”，应创建运行记录并自动打开运行详情；检查运行目标、服务、Revision 和任务状态。
7. 生产或审批环境用有 `workflow:approve` 权限的账号批准；开发只读账号只能查看授权项目和运行记录，不能执行或审批。
8. 回到工作流运行记录，确认环境名称、集群/Namespace 和运行状态正确；检查失败时的错误信息和日志入口。
