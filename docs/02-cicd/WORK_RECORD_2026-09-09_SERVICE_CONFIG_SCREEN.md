# 服务配置页面按截图收敛

## 交互边界

- 左侧服务目录右侧的 `+` 只用于创建服务目录，在目录内联填写服务名称。
- 编辑器顶部的 `+` 用于当前服务手动写入 YAML；旁边图标分别用于代码库导入和模板导入。
- 项目初始化、环境创建和工作流创建不出现在服务配置页面。

## 变量与编辑器

- 右侧展示检测到的服务组件、系统内置变量和自定义变量。
- 自定义变量默认包含 `cmd`、`cpuLimit`、`memoryLimit`、`port`、`replicas`，可添加和删除。
- YAML 中出现新的 `{{.变量名}}` 时自动补充变量行。
- “校验变量”检查 YAML 占位符是否都有变量定义。
- 保存 Revision 时写入变量 JSON 元数据，保留现有 YAML 定义兼容性。

## 数据库与重启

- 无新增 SQL。
- 后端无需重启。
- 前端开发环境刷新或重启 Web 服务；生产环境重新构建并重启 Web 服务。

## 验证

- `eslint`：CI/CD 项目工作区、服务创建器和服务工作台通过。
- 定向 `vue-tsc`：未发现本轮修改文件的错误。
- Vite 生产构建此前已通过；当前环境再次构建时被 Windows `spawn EPERM` 策略阻止。
