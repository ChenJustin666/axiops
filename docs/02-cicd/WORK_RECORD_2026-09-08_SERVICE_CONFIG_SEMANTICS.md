# 服务配置页语义与入口调整记录

## 需求修正

项目创建完成后进入项目概览；项目内“服务配置”负责维护服务定义，不负责展示环境发布矩阵。
环境、工作流、运行记录、制品等能力使用独立页签。

## 修改内容

- 页签名称：`服务与环境` → `服务配置`。
- 服务配置列表移除环境列和环境目标操作。
- 服务配置顶部提供“模板导入”和“Git 导入”；左侧服务目录 `+` 保留为通用添加入口。
- 服务创建向导支持来源预选：模板、Git、手工输入。
- 服务配置标题和说明改为 YAML/Helm 定义、变量、Revision 和构建配置语义。

## 数据库与重启

- 无 SQL 变更。
- 后端无需重启；前端开发服务需要刷新，生产环境需要重新构建并重启 Web 服务。

## 验证

- Prettier、ESLint 通过。
- 定向 `vue-tsc` 未发现项目工作区和服务创建向导错误。
- Vite 生产构建通过（6262 modules）。
