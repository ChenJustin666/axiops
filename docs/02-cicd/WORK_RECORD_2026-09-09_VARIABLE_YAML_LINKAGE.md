# YAML 与变量联动主路径修正

## 页面目标

服务配置页默认展示 YAML/Helm 编辑器和变量配置，不让 Revision、Diff 或服务概览成为进入页面后的遮挡层。

## 实现内容

- 工作台采用两栏主布局：左侧资源定义编辑器，右侧组件和变量面板。
- 编辑器顶部统一放置手动写入、代码库导入和模板导入三个入口。
- 左侧服务目录只负责服务选择、搜索和新建目录，不负责打开导入向导。
- 待定义服务进入页面时自动提供初始 YAML，可直接编辑并保存。
- 变量面板展示检测到的服务组件、镜像/构建入口、系统内置变量和自定义变量。
- YAML 中新增 `{{.xxx}}` 占位符会自动加入自定义变量；校验时检查未定义变量。
- Revision 保存同时写入变量元数据，重新加载时恢复变量列表。

## 数据库与重启

- 不需要 SQL。
- 后端不需要重启。
- 前端开发服务刷新即可；生产环境需要重新构建并重启 Web 服务。

## 验证

- 相关 Vue 文件 ESLint 通过。
- 定向 `vue-tsc` 未发现 `project-workspace` 及其服务编辑器文件错误。
