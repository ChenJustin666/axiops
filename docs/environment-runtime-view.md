# 环境运行资源视图

初始化完成后，项目的“环境”页用于观察目标集群实际资源。初始化配置流程保持原有入口。

选择开发、测试或生产环境后，下方概览与资源列表同时切换到该环境绑定的集群和命名空间。项目内上次选择保存在当前浏览器会话；失效的选择不会继续请求旧环境。生产有独立标识。

默认展示Deployment，可切换StatefulSet、DaemonSet、CronJob、Job，以及Pod、网络、存储、配置分类。显示命名空间内实际资源，包括非AxiOps创建的资源。列表镜像是集群当前资源声明的镜像，不是构建配置或待发布模板。

- 当前分类无资源只代表该分类为空，不据此推测整个环境未部署。
- API读取失败单独展示错误与重试，不伪装为空列表。
- 环境启用状态不是应用健康。Pod就绪、工作负载更新情况、Job完成条件来自Kubernetes状态。
- 只读取当前分类，支持名称过滤和手动刷新；可选每15秒刷新，页面隐藏、正在请求或查看详情时暂停。离开环境页停止刷新。
- 切换环境立即移除旧环境列表和详情；迟到的资源、详情、日志响应不能覆盖新环境。

“YAML / 事件”展示当前资源的实际YAML与按对象UID匹配的事件，事件由集群保留，历史可能已过期。Secret数据和注解不展示值。Pod日志可选容器及上次退出日志，读取最新500行且最多512KiB，点击刷新获取最新输出。初始化和临时容器也可选择。无Pod、未启动或旧日志被清理时，界面不能承诺存在日志。

“全局变量”和“环境资源配置”打开当前环境的配置入口。此处保存的内容属于待发布配置，后续部署才应用，实际资源列表不伪装成已生效。此页面不提供尚未接通的扩缩容、重启或交互终端按钮。主机环境不走Kubernetes查询。

新增只读接口（均沿用环境view权限并从环境解析目标，前端不传集群或namespace覆盖）：

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/environments/:id/resource-detail?kind=deployment&name=api` | 实际YAML与事件；资源类型白名单 |
| `GET /api/v1/environments/:id/pod-logs?name=api&container=app&previous=0` | 有界容器日志；校验容器属于该Pod |
