# 服务目录式创建入口修正记录

## 需求

服务配置页左侧服务目录的 `+` 应像文件管理器一样新增服务目录，目录中维护 deployment.yaml、service.yaml 等文件；不能点击 `+` 后弹出一个来源导航框。

## 实现

- `+` 直接创建手工服务目录并进入编辑器。
- 服务目录显示 YAML 文件节点，点击文件切换编辑文件。
- 增加“添加文件”内联输入，避免离开目录上下文。
- 模板导入和 Git 导入保留为旁边的独立入口。

## 数据库/重启

无 SQL。后端不需要重启；前端开发服务刷新即可，生产环境需重新构建并重启 Web 服务。

## 验证

Prettier、ESLint、定向 vue-tsc 均通过。
