# 服务目录 `+` 交互修正记录

## 问题

点击服务目录右侧 `+` 时错误打开了整页服务编辑器。该入口应当像文件管理器一样先创建服务目录，而不是重复项目初始化或打开来源选择向导。

## 实现

- `+` 点击后在左侧目录列表内显示服务目录名称输入框和“创建目录”按钮。
- 提交后创建一个手工服务元数据目录，自动生成合法服务编码，并立即在目录列表中选中。
- 目录创建不自动创建环境、工作流、构建配置或 Revision；这些内容在目录内部继续编辑。
- 模板导入与 Git 导入仍由页面顶部按钮触发，编辑服务仍使用服务操作菜单。
- 默认 K8s 文件使用真实换行生成，避免编辑器把整个 YAML 显示成一行并产生解析错误。

## 数据库与重启

- 不需要 SQL。
- 后端不需要重启。
- 前端开发服务刷新即可；生产环境需要重新构建并重启 Web 服务。

## 验证

- CI/CD 项目工作区及相关组件 ESLint 通过。
- 定向 `vue-tsc` 未发现本轮修改文件的错误。
