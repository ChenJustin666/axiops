# 服务文件树与三栏工作台

## 需求

服务创建完成后，服务配置页应进入 Zadig 风格的服务工作台：左侧服务目录，中间 YAML/Helm 文件编辑器，右侧变量和组件配置。项目初始化、环境创建和工作流创建不应再次出现在服务编辑页面。

## 实现内容

- 隐藏服务配置页原来的环境发布矩阵，保留项目独立的“环境”页签。
- 工作台中增加服务文件树，按 Revision 中的文件标记切换文件内容。
- 新建手工 K8s 服务默认生成 `deployment.yaml` 和 `service.yaml` 两个文件；Helm 服务默认生成 `Chart.yaml` 和 `values.yaml`。
- 保存时将文件按顺序编码为带 `# AxiOps-File:` 标记的多文档 YAML，读取 Revision 时逆向拆分。旧 Revision 没有标记时仍按单文件兼容读取。
- 右侧变量面板展示服务组件、系统变量和可增删的自定义变量，并提供本地变量校验。

## 数据库与运行

- 没有新增或修改 SQL，现有 `service_revision.definition` 字段即可保存串行化内容。
- 后端不需要重启。
- 前端开发环境刷新即可；生产环境需要重新构建并重启 Web 服务。

## 验证

- CI/CD 相关 Vue 文件 ESLint 通过。
- 定向 `vue-tsc` 未发现本次修改文件的错误；全量类型检查仍有仓库其他旧模块的既有错误。
- `npm.cmd run build` 通过，Vite 转换 6262 个模块。
