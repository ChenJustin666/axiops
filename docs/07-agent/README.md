# Agent 模块

## 产品设计

Agent 用于中心无法主动访问的内网、受限网络、特殊架构主机和集群。首期不把 Agent 变成通用远程执行后门。

## 需求

- HostAgent 支持主机身份、心跳、采集器管理和受控任务。
- ClusterAgent 支持内网集群代理、资源同步、日志和任务。
- 支持断线重连、任务幂等、日志批量回传和结果签名。
- 能力必须白名单化，敏感任务需要审批和审计。

## 技术设计

Agent 主动建立 mTLS 长连接；服务端维护能力、版本、心跳和任务租约。任务包含唯一 ID、过期时间、参数 schema、完整性校验和最小权限。

详细状态模型与采集策略见[DESIGN.md](DESIGN.md)。

## 实施计划

1. 定义注册、证书、心跳、能力和任务协议。
2. 实现服务端 registry 与任务队列。
3. 实现 HostAgent 最小版本。
4. 实现日志流、重试、升级和灰度。
5. 需要时再实现 ClusterAgent 和构建能力。

## 完成进度

- 已完成：使用边界和参考方案确认。
- 未开始：目标协议代码、服务端 registry 和 Agent 二进制。

## 验收标准

- Agent 失联不会造成任务重复执行。
- 任意任务可追踪下发人、权限、参数、输出和结果。
- Agent 无法执行未注册能力或过期任务。
