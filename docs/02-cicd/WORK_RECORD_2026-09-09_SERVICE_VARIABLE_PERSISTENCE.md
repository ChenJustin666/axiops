# 服务变量持久化与运行时变量契约

## 变量持久化

服务创建或手工保存 Revision 时，变量表以 `# AxiOps-Variables:` JSON 元数据写入现有 `service_revision.definition` 字段。重新加载服务会先解析该元数据，再展示变量列表，因此不会因页面刷新而恢复成默认值。

## 运行时变量

- `$Product$`：项目名称，例如 `picc03`。
- `$Service$`：服务编码，例如 `web-lib`。
- `$<service>-image$`：服务镜像变量，例如 `$web-lib-image$`。
- `$Namespace$`、`$EnvName$`、`$ClusterName$`：服务配置阶段保持未绑定状态，在环境发布时由目标环境注入。
- `domain`：服务级域名变量，为 Ingress/二级域名模板预留。

## UI 调整

- 变量配置区采用白色背景，绿色用于组件和校验，红色用于删除。
- 编辑器保持独立深色区域；服务目录文件可逐个切换编辑。
- 服务配置不再显示项目初始化字段，只显示服务目录文件。

## 数据库与重启

- 不需要新增或执行 SQL，复用已有 Revision 字段。
- 后端无需重启；前端开发服务刷新即可，生产环境需重新构建并重启 Web 服务。

## 验证

- CI/CD 相关 Vue 文件 ESLint 通过。
