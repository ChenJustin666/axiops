# 资产管理模块

## 产品设计

统一管理云主机、物理机、虚拟机及后续 RDS、Redis、SLB、VPC 等资源，作为监控、Agent、项目分配和运维操作的资源目录。

## 需求

- 支持阿里云、腾讯云，并扩展 AWS、华为云和私有云。
- 支持云 API 同步、手工录入、去重、变更记录和失联标记。
- 支持项目、环境、区域、用途和主机组。
- 支持基于资产批量安装采集器或 Agent。
- 凭据加密且不向普通用户返回明文。

## 技术设计

云 provider 负责发现，资源目录负责统一 ID、归属、标签和生命周期。同步任务由 worker 异步执行，采用幂等 upsert，原始云 ID 与平台 ID 分离。

## 实施计划

1. 盘点并复用阿里云、腾讯云同步代码。
2. 定义统一 asset、cloud_account、resource_binding 和 host_group。
3. 实现增量同步、删除保护和审计。
4. 接入项目权限、监控采集和 Agent 安装。

## 完成进度

- 已完成：旧代码存在阿里云和腾讯云主机同步基础。
- 未完成：目标统一资源模型、跨云 provider 接口和授权过滤。

## 验收标准

- 同一资产不会因重复同步产生重复记录。
- 云端删除先进入失联/待确认状态，不直接破坏平台数据。
- 用户只能看到授权项目或主机组资产。
