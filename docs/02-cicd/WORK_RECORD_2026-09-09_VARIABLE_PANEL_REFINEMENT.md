# 变量面板与导入入口再优化

## 本轮修正

- 默认主路径为 YAML/Helm 编辑器与右侧变量面板，Revision、Diff、服务概览只作为次级 Tab。
- 服务列表删除冗余状态筛选，保持搜索和目录创建。
- 编辑器顶部统一提供手动写入、代码库导入、模板导入入口。
- 待定义服务自动加载可编辑初始定义，不再停留在白底空态。
- 变量面板展示服务组件、构建入口、系统内置变量和可增删自定义变量。
- YAML 占位符变化会自动补充变量；变量校验会提示未定义占位符。
- “预览变量”模式根据右侧变量即时渲染左侧 YAML，编辑模式仍保留原始模板。

## SQL 与重启

- 无 SQL。
- 后端无需重启。
- 前端开发环境刷新或重启 Web 服务即可；生产环境需要重新构建并重启 Web 服务。

## 验证

- CI/CD 相关 ESLint 通过。
- 定向 `vue-tsc` 未发现本轮修改文件错误。
