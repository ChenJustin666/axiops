# 部署日志

打开项目 → 工作流 → 执行记录 → 单次运行，点击部署节点。

- **简洁**（默认）：展示目标集群和命名空间、资源提交、最新就绪进度、异常记录及最终结果。相同检查和常规事件合并，容器退出码、重启次数、探针失败、调度/拉镜像错误和超时原因保留。
- **详细诊断**：查看该任务保存的诊断文本。旧记录不会被简洁视图改写。遇到未知错误、多容器问题、需要核对原始 Kubernetes conditions/events 时使用此视图。
- 两种视图均可全屏、自动换行、跳到顶部或末尾；切换全屏保留所选模式。构建和测试的容器输出仍按原样显示。

简洁视图是已保存诊断的摘要，不是新的实时集群查询。重复轮询次数不会当成错误发生次数；重启次数取自保存的容器状态。时间中的 `Z` 表示 UTC。

新部署在后台只追加变化的状态和新的事件，减少重复写入。状态恢复后再次失败仍会记录。原有日志大小和事件数量上限继续生效，达到上限会显示提示；“详细诊断”表示已保存的诊断，不保证包含集群全部历史事件或应用 stdout/stderr。

例如 `CrashLoopBackOff`、`exitCode=1` 和探针 `connection refused` 会在简洁视图中保留。要继续定位应用启动异常，可到目标环境的运行资源中查看对应 Pod 的容器日志。
