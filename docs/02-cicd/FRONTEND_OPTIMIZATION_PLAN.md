# CI/CD 前端优化实施计划

## 目标

面向运维快速上线，沿用 Zadig 的“项目 -> 服务 -> 环境 -> 工作流”主路径，
在不绕过权限、审批和审计的前提下，减少页面跳转并提升批量操作效率。

## 优先级与顺序

### P0：必须先完成

1. [已完成] 项目工作台服务×环境矩阵：按项目实际环境动态生成列，支持测试/生产两环境项目。
2. [已完成] 服务详情三栏：服务目录、资源/组件配置、Revision/Diff/环境引用。
3. [已完成] 环境服务覆盖编辑：结构化副本/镜像/资源参数，保留基线定义查看和预览 Diff。
4. [已完成] 工作流运行目标：只展示已授权、已验证的环境和集群目标，生产继续强制审批。
5. [已完成] 运行详情：显示源码 Commit、构建产物 digest、阶段状态、目标 Job 和日志入口。

### P1：完成核心交付后实施

1. [已完成] 同级目录批量同步，多服务目录选择、YAML 扫描、校验和 Revision 批量创建。
2. 快速发布三步向导：选择服务/版本、选择环境/目标、Diff 与审批确认。
3. 多集群目标批次和失败暂停/继续，保持一个环境下每个目标独立 Job。
4. 测试节点和测试报告，确保 `build -> test -> deploy` 顺序可配置。

### P2：平台化增强

1. Helm 模板库、模板版本和 values 差异化管理。
2. 服务依赖图、影响分析和依赖契约校验。
3. 可配置晋升链和 artifact 门禁，例如 `test -> prod` 或 `dev -> test -> stage -> prod`。
4. 2000+ 服务搜索、标签分组、我的服务/待发布/失败等保存视图。

### P3：企业增强

1. 金丝雀/蓝绿能力检测、指标门禁和自动回滚。
2. 字段级权限、风险豁免、变更窗口和生产镜像限制。
3. 成本中心、SBOM/签名、日志指标 Trace 关联、变更日历和灾备演练。
4. 驾驶舱全局统计和紧急回滚入口。紧急入口必须使用独立权限、审批/审计和回滚快照，不能绕过治理。

## 本轮完成

- 概览页增加服务×环境矩阵，环境列按项目配置动态生成。
- 单元格状态区分“可发布”“待导入”“待验证”，生产单元格提示仍需审批和制品门禁。
- 矩阵点击可进入环境配置；无服务或无环境时显示空状态，不生成虚假环境。
- 服务列表新增详情入口，打开三栏详情抽屉：左侧服务元信息与 Revision 历史，中间资源定义/Revision 对比，右侧环境引用。
- 详情抽屉的编辑、定义同步、构建配置和环境配置动作复用现有权限保护的弹窗和接口。
- 构建配置入口额外受 `build_config:view` 控制，详情页不展示越权操作。
- 环境覆盖弹窗显示目标、基线 Revision、覆盖 Revision 和字段级差异；副本/镜像仍通过受保护的现有覆盖 API 保存。
- YAML/Helm 基线定义在环境配置中以只读方式展开，资源结构修改必须创建新的服务 Revision，避免覆盖基线。
- 工作流执行弹窗只列出类型匹配、状态启用且绑定已验证的环境；目标卡片显示环境、集群/Namespace 或主机组以及生产审批要求，无可用环境时提供明确配置入口。
- 运行记录使用环境名称和实际资源绑定替代裸 ID；运行详情显示发布目标、触发方式、服务、构建编号、分支、Commit 链接、变更链接、镜像 digest、构建阶段、Job/Pod/节点及日志入口。
- 工作流编排器原有的 Vue Flow 可选数据空值检查已完善，本模块定向 `vue-tsc` 不再报错。
- 未新增 API、SQL 或后端运行逻辑，保持现有权限校验和工作流模型。

## 验收要求

- 只有 `test`、`prod` 的项目，矩阵和工作流目标只显示这两个环境。
- 未导入 Revision 的服务不能显示为可发布。
- 未验证的集群/主机环境不能显示为可发布。
- 开发者只读权限下不显示服务/环境写操作，后端仍复核每次请求。
- 前端目标文件必须通过 Prettier 和 ESLint；涉及后端时补充 Go 单元/API 测试。
