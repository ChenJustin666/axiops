# 服务文件树位置与编辑态修正

## 页面行为

- 文件节点归属于左侧服务目录：选择服务后在服务项下展开 YAML 文件。
- 中央区域仅显示当前选中的一个文件，保持稳定宽度，类似 VS Code 编辑器。
- 服务编辑器不再在内部重复渲染文件树。

## 编辑与视觉

- 编辑器改用浅色主题，白色配置区、浅灰边框、绿色操作强调和红色删除操作。
- `canEdit` 为真时进入页面即允许编辑；权限不足时显示只读状态，保存仍由后端授权保护。
- 无 Revision 的服务自动提供可编辑初始 YAML。

## 数据库与重启

- 无新增 SQL。
- 后端无需重启；前端刷新或重启 Web 服务即可。

## 验证

- CI/CD 相关 ESLint 通过。
- 定向 `vue-tsc` 未发现本轮修改文件错误。
