# 服务配置单页编辑器修正记录

## 需求

项目创建已经完成后，点击服务配置的 `+` 只能进入“新建服务”页面。不能再次出现项目配置、创建环境、执行工作流等项目初始化步骤。

## 实现

- 删除服务创建器中的项目初始化步骤和初始化预览区。
- 保留服务目录、YAML 文件树、模板/Git 导入、变量、YAML/Helm 编辑器和 Revision 保存。
- 保存按钮只执行服务元数据和 Revision 保存。
- 增加服务删除入口，使用现有 `DELETE /cicd/v1/services/{id}` API，并在前端二次确认。

## 数据库与重启

- 无 SQL 变更。
- 后端不需要重启；前端开发服务刷新即可，生产环境需重新构建并重启 Web 服务。
